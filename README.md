# matlab-scripts

Public repository of past MATLAB scripts used for professional and university applications.

## Repository contents

- Standalone MATLAB utilities for structural and mechanical calculations.
- Example data files used by selected scripts.
- `MCAUnbound/`, a Java-based Minecraft mod project that is versioned alongside the scripts.

## Notes

Most MATLAB files are self-contained and can be run directly in MATLAB. Review each script header and in-file comments for required inputs and assumptions.
